# 02 - Git and GitHub Basics

## Commands I practiced

- `git log --oneline`: see the history
- `git diff`: see what changed before I save it
- `git switch -c name`: make a branch and move to it
- `git merge name`: join a branch into the one I am on
- `git push -u origin name`: send a new branch to GitHub

## What I learned

- A branch is only a pointer to a commit. Nothing is copied.
- A conflict happens when both sides change the same line.
- A branch stays on my computer until I push it.
