# DevOps Journey

Hands-on DevOps practice, built from zero. Every task has its own folder with notes on what I built, why, and what I learned.

## About me

I'm an Information Technology undergraduate at Horizon Campus, Sri Lanka, focused on DevOps and cloud engineering.
I did a DevOps internship at Codezela Technologies, working with Linux, Docker, cloud infrastructure, monitoring, and troubleshooting.
This repo is where I rebuild and practice the full DevOps path, step by step.

## Repo layout

Each folder is one section. Inside, a README explains the task: what I built, why it matters, the commands I ran, and what I learned.

## Safety

No secrets are stored here. Keys, `.env` files, and `.pem` files are ignored.
AWS work runs on the free tier. Servers are stopped after each session and terminated at the end.
